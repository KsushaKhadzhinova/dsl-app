# ИТиВП, Часть 1 — Лабораторная работа 4: Адаптивная вёрстка

Ветка: `feature/responsive-layout` (от `main`, влита обратно в `main`).

## Подход: mobile-first

Базовые правила в `frontend/css/style.css` без медиа-запросов рассчитаны на мобильный экран
(колонки в один столбец, `flex-direction: column`). Расширения идут только вверх через
`min-width`, ничего не переопределяется вниз.

## Точки перелома

- База (`< 600px`): один столбец везде, шапка и навигация друг под другом, hero без картинки сбоку.
- `≥ 600px` (планшет): шапка в строку, сетка карточек 2 колонки, нотации и автор — в строку.
- `≥ 1024px` (десктоп): hero в две колонки (текст + картинка), сетка карточек 4 колонки, увеличенные заголовки, более широкие отступы контейнера.

## Технологии

- **Flexbox** — шапка, hero, блок нотаций, карточка автора (там, где порядок и выравнивание важнее сетки).
- **CSS Grid** — `.features__grid` (карточки возможностей: 1 → 2 → 4 колонки по брейкпоинтам через `grid-template-columns`).
- **CSS-переменные** (`:root`) — цвета, отступы (`--spacing-unit`), ширина контейнера (`--container-width`) — переиспользуются во всех медиа-запросах без дублирования значений.
- **Медиа-запросы** — `min-width: 600px` и `min-width: 1024px`.

## Проверка

Проверялось на трёх ширинах вьюпорта (адаптивный режим DevTools/Browser pane): 375px (мобильный),
768px (планшет), 1280px (десктоп) — раскладка не ломается, текст не переполняет контейнеры, изображения масштабируются (`max-width: 100%`).

## Исправление после сверки с полным текстом задания

Задание прямо просит разбить CSS на `variables.css`, `base.css`, `header.css`, `main.css`,
`footer.css`, `adaptive.css` + общий `style.css`, который их импортирует — изначально всё
лежало в одном `style.css`. Исправлено на ветке `feature/responsive-layout` (отдельный
коммит после первоначального): CSS разложен ровно по этой структуре
(`style.css` теперь состоит только из шести `@import`).

Заодно добавлено то, что задание явно требует, но изначально было пропущено: бургер-меню
для мобильной навигации (`.site-header__menu-toggle`, `.site-nav--open`) — HTML-разметка
и стили подготовлены здесь, а переключение по клику подключено в Lab 5 (ровно как написано
в самом задании: "JavaScript для переключения класса добавляется в следующей работе, но
HTML-структуру и базовые стили нужно подготовить сейчас").

## Тесты

Ретроактивно покрыто в рамках Lab 5: `frontend/tests/responsive.test.js` проверяет исходники
`style.css` — наличие CSS-переменных, mobile-first порядок правил (базовые стили до первого
`@media`), оба брейкпоинта (600px/1024px), использование Flexbox и Grid. Это статическая
проверка кода, а не рендеринга — реальная раскладка на разных ширинах экрана всё равно
проверяется вручную (см. ниже), так как jsdom не считает реальный layout.
