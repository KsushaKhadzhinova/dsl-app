## Ответы на контрольные вопросы

1. **VS Code vs текстовый редактор** — интегрированный терминал, встроенный Git (Source Control), IntelliSense/автодополнение, расширяемость (Prettier/GitLens и т.п.) — всё в одном окне вместо переключения между приложениями.
2. **Git в VS Code** — `git init` → стадирование через вкладку Source Control (аналог `git add`) → коммит с сообщением → `git push` в удалённый репозиторий; весь цикл без выхода в отдельный терминал.
3. **Node.js/npm** — Node даёт JS-рантайм вне браузера (нужен для сборщиков, dev-серверов, будущего Express-бэкенда лаб 2 части курса); npm — управление зависимостями и скриптами (`npm run dev` и т.п.), без него пришлось бы вручную скачивать и подключать каждую библиотеку.
4. **Figma** — визуальное проектирование интерфейса и цветовой/шрифтовой системы до написания кода; для DiagramCode особенно полезны Auto Layout (для сложных панелей IDE) и экспорт токенов (цвета/шрифты) прямо в CSS-переменные.
5. **Настройка VS Code** — Format On Save + Prettier (единый стиль кода без ручного форматирования), .gitignore (не тащить `node_modules` в репозиторий), рабочее пространство с открытой всей монорепо-папкой, а не только `frontend/`.
6. **.gitignore** — исключает файлы, которые не должны попадать в репозиторий (генерируемые, окружения, секреты). Пример для веб-проекта: `node_modules/`, `.env`, `*.log`, `.DS_Store`.
7. **Именование папок/проекта** — использовать английские, без пробелов, отражающие суть (`diagramcode`, а не `лаба2` или `project1`) — облегчает расширение до полноценного продукта и деплой (многие хостинги не любят кириллицу/пробелы в путях).
8. **git add/commit/push** — `add` переносит изменения в staging area (что попадёт в следующий коммит), `commit` фиксирует снимок с сообщением локально, `push` отправляет локальные коммиты в удалённый репозиторий.
9. **Проверка настроек Git** — `git config --global user.name` / `user.email` (без флага выводят текущее значение); изменить — та же команда с новым значением.
10. **Что не коммитить** — `node_modules/` (пересобирается из `package.json` командой `npm install`, весит сотни МБ, версии зависят от ОС) — коммитить бинарные пересобираемые артефакты бессмысленно и раздувает репозиторий.
