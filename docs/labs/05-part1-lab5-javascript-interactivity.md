# ИТиВП, Часть 1 — Лабораторная работа 5: JavaScript-интерактивность

Ветка: `feature/javascript-interactivity` (от `main`, влита обратно в `main`).

## Интерактивные компоненты (3, требуется ≥2)

1. **Переключатель темы** (`#theme-toggle`) — переключает `data-theme` на `<html>` между `dark`/`light`, тема сохраняется в `localStorage` (`dc-theme`) и восстанавливается при следующей загрузке страницы.
2. **Фильтр нотаций** (`#notations-filter`) — живой поиск по списку нотаций через `input`, скрывает несовпадающие пункты (`hidden`), показывает сообщение "Ничего не найдено" при пустом результате.
3. **FAQ-аккордеон** (`.faq__question`) — кастомный (не `<details>`) аккордеон: клик или `Enter`/`Space` разворачивает/сворачивает ответ, `aria-expanded` синхронизируется с состоянием.

## Типы событий (3, требуется ≥3)

- `click` — переключатель темы, вопросы FAQ.
- `input` — фильтр нотаций.
- `keydown` — клавиатурная активация FAQ (доступность для пользователей без мыши).
- (`DOMContentLoaded` — инициализация, не входит в обязательные 3, но используется для запуска остальных обработчиков только после готовности DOM).

## Работа с DOM

Без фреймворков: `document.getElementById`, `querySelectorAll`, `classList`/`setAttribute`, `textContent`, свойство `hidden` — прямое управление видимостью и состоянием элементов.

## LocalStorage

Ключ `dc-theme`, значение `'dark'` или `'light'`. Файл: `frontend/js/script.js`, функции `applyTheme`/`initThemeToggle`.

## Исправление после сверки с полным текстом задания

Задание прямо просит структуру `js/script.js` + `js/components/` + `js/utils/` — изначально
всё лежало в одном `js/script.js`. Исправлено на ветке (отдельный коммит): код разложен на
`components/{themeToggle,notationsFilter,faqAccordion,burgerMenu,subscribeForm}.js` +
`utils/storage.js` (обёртки `readJSON`/`writeJSON` над `localStorage`), всё через настоящие
ES-модули (`import`/`export`, `<script type="module">`) — это чище, чем полагаться на общую
глобальную область видимости классических `<script>`-тегов, и ровно тот же паттерн, который
задание само использует в примерах для Lab 6.

Добавлено то, что изначально было пропущено:
- **Бургер-меню** — `components/burgerMenu.js` подключает клик по кнопке из Lab 4 к
  классу `.site-nav--open` и обновляет `aria-expanded`/`aria-label`.
- **Форма с валидацией (Часть 5)** — блок «Быть в курсе обновлений»: email-подписка с
  проверкой на пустоту и формат, выводом ошибки и сохранением подписчиков в LocalStorage
  (`components/subscribeForm.js`) — ранее в проекте не было ни одной формы вообще, хотя
  задание явно просит её при применимости к теме проекта.

## Тесты

Jest + jsdom (`frontend/tests/script.test.js`), 21 тестов на все функции `script.js`
(переключение темы, включая ветку "кнопки нет на странице"; фильтр нотаций, включая
все три ветки отсутствующих элементов; FAQ-аккордеон через клик и через клавиатуру,
включая "прочие клавиши не должны ничего переключать"). Запуск: `npm test` в `frontend/`.

Фактически подтверждено прогоном: **100% statements / branches / functions / lines**
по `js/script.js`, порог закреплён в `package.json` (`coverageThreshold`), так что
регресс покрытия в будущем завалит `npm test`.
