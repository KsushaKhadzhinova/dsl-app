# AI-провайдер: заглушка сейчас, инструкция подключения на потом

Отвечает на вопрос 6 из раунда уточнений: ключа под рукой пока нет — система работает на заглушке (`StubAIProvider`, уже в коде: `backend/app/integrations/ai/stub_provider.py`) и не падает без ключа. Когда ключ появится у любого из провайдеров ниже — подключение занимает одну строку в `.env`.

## Как это устроено в коде

`app/domain/interfaces.py` определяет протокол `AIProvider` (2 метода: `generate_dsl_from_text`, `fix_dsl`). Всё остальное приложение (`services/`, `worker/tasks.py`) зависит только от этого протокола, никогда от конкретного провайдера — фабрика `app/integrations/ai/get_ai_provider()` подставляет нужную реализацию по значению `AI_PROVIDER` в `.env`:

```
AI_PROVIDER=stub       # по умолчанию — ничего не требует, ничего не ломает
AI_API_KEY=            # пусто = гарантированно используется заглушка
```

Чтобы подключить реального провайдера, нужно: (1) получить ключ по инструкции ниже, (2) вписать его в `.env`, (3) поменять `AI_PROVIDER` на нужное значение. Никакого другого кода менять не нужно — это и есть смысл Strategy-паттерна за интерфейсом (см. `docs/literature/bibliography.md`, [41]).

## Anthropic (Claude) — `AI_PROVIDER=anthropic`

1. Зайти на **console.anthropic.com** и зарегистрироваться (email или Google-аккаунт).
2. В разделе **API Keys** (левое меню) нажать **Create Key**, дать ему имя (например, `diagramcode-dev`).
3. Скопировать ключ (вида `sk-ant-...`) — он показывается один раз, если потерял — создать новый.
4. Пополнить баланс в разделе **Billing** (у Anthropic нет постоянного бесплатного тарифа для API, но есть периодические промо-кредиты для новых аккаунтов — проверить при регистрации) **или** узнать про **Anthropic для образования/студентов** — иногда доступны гранты API-кредитов по учебной почте.
5. В `.env` проекта:
   ```
   AI_PROVIDER=anthropic
   AI_API_KEY=sk-ant-...
   ```
6. В коде уже есть заготовка интерфейса — не хватает файла `backend/app/integrations/ai/anthropic_provider.py` (создаётся по образцу `stub_provider.py`, вызывает `https://api.anthropic.com/v1/messages` через `httpx`, модель `claude-*`).

## OpenAI (GPT) — `AI_PROVIDER=openai`

1. Зайти на **platform.openai.com**, зарегистрироваться.
2. **Settings → API Keys → Create new secret key**.
3. Скопировать ключ (вида `sk-...`).
4. В **Billing** привязать способ оплаты — у OpenAI тоже нет вечного бесплатного тарифа для API (не путать с ChatGPT Plus — это отдельная подписка, ключ API не даёт).
5. `.env`:
   ```
   AI_PROVIDER=openai
   AI_API_KEY=sk-...
   ```
6. Аналогично потребуется файл `openai_provider.py` (эндпоинт `https://api.openai.com/v1/chat/completions` или Responses API).

## Google Gemini — бесплатный тариф есть, хороший первый выбор

1. Зайти на **aistudio.google.com**, войти обычным Google-аккаунтом.
2. Нажать **Get API key → Create API key**.
3. Ключ появляется сразу, без привязки карты — у Gemini есть щедрый бесплатный тариф (лимит запросов в минуту/день, обновляется, точные цифры смотреть в **aistudio.google.com/app/plan_information**, они периодически меняются).
4. `.env`:
   ```
   AI_PROVIDER=gemini
   AI_API_KEY=AIza...
   ```
5. Требует `gemini_provider.py` (эндпоинт `generativelanguage.googleapis.com`).

## Groq — бесплатно, но модели послабее, зато очень быстрый инференс

1. **console.groq.com**, регистрация.
2. **API Keys → Create API Key**.
3. Бесплатный тариф без карты, лимиты по запросам в минуту.
4. `.env`:
   ```
   AI_PROVIDER=groq
   AI_API_KEY=gsk_...
   ```

## OpenRouter — один ключ, доступ к десяткам моделей (включая бесплатные)

1. **openrouter.ai**, регистрация.
2. **Keys → Create Key**.
3. У OpenRouter есть модели с пометкой `:free` в названии — доступны без пополнения баланса (с ограничением запросов в день). Хороший вариант, если хочется попробовать разные модели одним ключом, не регистрируясь везде.
4. `.env`:
   ```
   AI_PROVIDER=openrouter
   AI_API_KEY=sk-or-...
   ```

## Рекомендация для старта (без затрат)

**Google Gemini** или **OpenRouter (`:free`-модели)** — оба дают рабочий бесплатный доступ без привязки карты, этого достаточно, чтобы довести AI-режимы (`write` / `fix_code` / `fix_error` / `docs`, см. требования из раунда «мне нужно чтобы было») до рабочего состояния ещё до того, как встанет вопрос об оплате. Anthropic/OpenAI можно подключить позже как более качественную, но платную альтернативу — благодаря `AIProvider`-интерфейсу это переключение одной переменной, а не переписывание кода.

## Что ещё нужно сделать в коде, когда ключ появится

1. Создать `backend/app/integrations/ai/<provider>_provider.py`, реализующий `generate_dsl_from_text` и `fix_dsl` (сигнатуры — в `app/domain/interfaces.py`).
2. Зарегистрировать его в `app/integrations/ai/__init__.py::get_ai_provider()` (там уже есть ветки-заготовки `if settings.ai_provider == "anthropic": ...` — только добавить импорт для новых провайдеров).
3. Написать системный промпт, жёстко ограничивающий модель форматом ответа (только код DSL, без пояснений вокруг) — критично, иначе `dsl/parser.py` не сможет распарсить ответ. Черновик системного промпта уже возможно набросать из cheat sheet DSL (`docs/architecture/00-system-architecture.md`, грамматика в `backend/app/dsl/grammar.lark`).
