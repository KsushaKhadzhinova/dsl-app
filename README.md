# ИТиВП, Часть 2 — Практическое занятие 1

Middleware и шаблонизатор EJS поверх проекта из Лабораторной работы 1 (диаграммы DiagramCode, хранение в массиве).

## Запуск

```bash
npm install
npm run dev
```

Открыть `http://localhost:3000` (без `?auth=1` — пользователь "Гость", с `?auth=1` — имитация авторизации).

## Тесты

```bash
npm test
```

Порог покрытия — 100%.

## Страницы

| Маршрут       | Метод | Описание                          |
|---------------|-------|------------------------------------|
| /             | GET   | список диаграмм                    |
| /item/:id     | GET   | детальная страница диаграммы       |
| /add          | GET   | форма добавления диаграммы         |
| /add          | POST  | создание диаграммы, редирект на /  |

## Middleware

- `middleware/logger.js` — логирует метод, URL и время запроса.
- `middleware/fakeAuth.js` — имитация авторизации через `?auth=1`.
- `middleware/errorHandler.js` — рендер `404.ejs` / `500.ejs`.
