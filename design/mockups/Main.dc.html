Зоны интерфейса

1
Верхняя панель — логотип, селектор нотации, путь к файлу, кнопки Run / Save / Export / Import / AI, аватар пользователя.
2
Activity Bar — переключение между шаблонами, поиском, отладкой, историей версий.
3
Сайдбар «Templates» — список нотаций с цветовой меткой и список открытых файлов.
4
Редактор кода — DSL с подсветкой синтаксиса; изменяемая ширина через resize-handle.
5
Канвас диаграммы — визуальный рендер в стиле draw.io, синхронизирован со строкой в редакторе.
6
Нижняя панель — вкладки Terminal / Problems, вывод результата парсинга и рендера.
7
Статус-бар — статус синхронизации, активная нотация, позиция курсора, кодировка, язык интерфейса.
